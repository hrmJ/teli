# Tekstit liikkeessä (teli)

This repository contains the source code and infrastructure for running the 
Tekstit liikkeessä (teli) database.

To find out more, look at:

- `docs/app_structure.md`  for a general overview of what's inside and the
  design principles involved in organizing the different pieces of the software
- `docs/deploying.md`  for instructions on how to update a new version and Ci/Cd
- `docs/running_tests.md` - running different tests locally
